Future Prediction as Training-Only Video Supervision for Pretrained VLA Policies

Future-video prediction improves a pretrained VLA during fine-tuning. At deployment, the video branch is removed and the original action pathway is retained.

01 / Overview

Future video becomes a training signal.

Future frames in robot demonstrations describe object motion and task progress beyond the action labels.

We turn those observations into an auxiliary learning signal for the shared VLA representation. The video branch is used only during training.

02 / Method

Train with video. Act with the VLA.

Two objectives shape a shared representation. Only the original action pathway is retained at deployment.

  1. 01 / Encode

    Build policy and visual conditions.

    A trainable adapter connects the shared VLM to video cross-attention; a VACE condition network supplies current-frame visual information.

  2. 02 / Optimize

    Combine action and video objectives.

    Flow-matching video loss is evaluated only on valid future latent blocks, alongside the original action objective.

  3. 03 / Deploy

    Remove the auxiliary expert.

    The updated shared prefix and action expert retain the original action-generation pathway.
